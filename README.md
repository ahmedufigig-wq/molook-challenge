# ملوك التحدّي — إصدار اللمة

لعبة جماعية عربية تعمل دون إنترنت (`com.molook.challenge`).

## الحالة الحالية
نسخة أولية: هيكل مشروع Android + Compose + واجهة RTL.
**لم تُنفَّذ بعد:** الغرف، الشبكة، الألعاب، الحسابات، الإحصائيات.
هذا الملف لم يُترجَم ولم يُختبَر قبل التسليم؛ أول بناء على GitHub هو أول اختبار فعلي.

## كيف تحصل على APK (بدون تثبيت أي برنامج)
1. ارفع كل محتويات هذا المجلد إلى مستودع GitHub جديد (الفرع `main`).
2. افتح تبويب **Actions**، وانتظر انتهاء «Build APK» (3 إلى 6 دقائق).
3. افتح التشغيل الناجح، ونزّل `molook-challenge-debug-apk` من قسم Artifacts، ثم فك الضغط.
4. انقل `app-debug.apk` إلى هاتفك وثبّته (فعّل «التثبيت من مصادر غير معروفة»).

## إن فشل البناء
انسخ نص الخطأ من صفحة التشغيل في Actions وأرسله لي لأصلحه.
